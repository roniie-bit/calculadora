# Calculadora

Calculadora web sencilla para operaciones cotidianas. Incluye suma, resta, multiplicación, división, porcentajes, decimales y control con teclado.

## Uso

Abre `index.html` en tu navegador. No requiere instalación ni dependencias.

### Teclado

- Números y `.` para escribir valores
- `+`, `-`, `*`, `/` para elegir una operación
- `Enter` o `=` para calcular
- `Escape` para borrar todo
- `Backspace` para borrar el último dígito

## Tecnologías

HTML, CSS y JavaScript nativos.
